1. Sign in to [Power Apps](https://make.powerapps.com/) and select your environment.

1. Select **Solutions** and open the **Field Service Project Operations Integration solution**.

   :::image type="content" source="../field-service/media/project-operations-integration-power-apps-solution.png" alt-text="Screenshot of Power Apps solutions showing the Field Service Project Operations Integration Solution.":::

1. From **Objects**, select **Cloud flows** and then search for **Process Work Order Line Revision**.

1. Ensure the **Status** is set to *On*.

   :::image type="content" source="../field-service/media/project-operations-integration-power-apps-flow.png" alt-text="Screenshot of Power Apps showing the cloud flow with status set to on.":::

To use Copilot and generative AI features that require cross-region processing, enable the **Move data across regions** setting for each environment. Before enabling the setting, review the processing destinations and applicable data residency requirements at [Regions where data is processed for Copilots and generative AI features](/power-platform/admin/geographical-availability-copilot#regions-where-data-is-processed-for-copilots-and-generative-ai-features). If you don't turn on the setting, affected features might become unavailable.

Enable the **Move data across regions** setting for each affected environment:

1. Sign in to the [Power Platform admin center](https://admin.powerplatform.microsoft.com/).

1. Select **Manage** > **Environments** and select your environment.

1. For **Generative AI features**, select **Edit**.

1. Review the terms of use, select the **Move data across regions** checkbox, and then select **Save**.

For more information about this setting, see [Move data across regions for Copilots, AI agents, and generative AI features](/power-platform/admin/geographical-availability-copilot).

# Use Copilot filters

[!INCLUDE[cc-feature-availability-cs-only](../../includes/cc-feature-availability-cs-only.md)]


Use Copilot filters to generate responses from a specific set of articles. Filters provide context and help reduce irrelevant responses.

> [!NOTE]
> For the expected responses, make sure relevant knowledge content is available for the filters you select.

Depending on your administrator's filter settings, you can:

- Select filters to refine Copilot responses.
- View and edit automated filters that apply based on the current record.

Automated filters can also run in the background without being available to view or edit.

For example, if you handle only credit card queries, apply a credit card filter. Copilot then uses only the relevant credit card content from the knowledge source to generate responses.
 
If automated filters are enabled for the case based on the location of the customer's account, Copilot applies the filter automatically when you open the case. You can change the filter as required.

When both filters apply, Copilot uses both to generate responses.

To apply a filter:

1. Select **Filters** on the Copilot pane. The **Select filters** menu appears.
1. Select the required options. You can also search for an option.
1. Select **Apply**.

After you set a filter:
- A message on the Copilot pane indicates that filters apply when Copilot generates a response or you change the filter configuration.
- An indicator next to **Filters** shows the number of selected filter options.
- An indicator identifies the automated filter.
- Filters apply when you ask a question, draft a chat response, or draft an email.
- Your filter is saved, so you don't need to set it each time you sign in.

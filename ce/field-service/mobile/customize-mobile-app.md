# Customize the Field Service mobile app

The Field Service mobile app is built on Microsoft Power Platform as a [model-driven app](/powerapps/maker/model-driven-apps/model-driven-app-overview), which makes it customizable to your business needs.

You can customize the mobile app in various ways, including, but not limited to:

- [Add a custom app module](/dynamics365/guidance/resources/field-service-mobile-add-custom-app)
- [Add custom service reports](/dynamics365/guidance/resources/field-service-service-reports-solution)
- [Automate business processes through workflows and scripts](/dynamics365/guidance/resources/field-service-mobile-automate-business-processes)
- [Customize the mobile app booking view](/dynamics365/guidance/resources/field-service-mobile-customize-booking-view)
- [Edit the booking and work order form](/dynamics365/guidance/resources/field-service-mobile-change-work-order-booking-form)
- [Edit the navigation and views](/dynamics365/guidance/resources/field-service-mobile-edit-navigation-views)
- [Enable dynamic font scaling](/power-apps/mobile/mobile-new-look#enable-dynamic-font-scaling)
- [Use deep links to other apps](/dynamics365/guidance/resources/field-service-mobile-use-deep-links)
- [Use Power Apps to configure the mobile app](/dynamics365/guidance/resources/field-service-mobile-customize-powerapps)

For a brief description, see [Field Service mobile app customizations](/dynamics365/guidance/resources/field-service-sample-library#field-service-mobile).

Add custom controls to the mobile app to enhance the user experience. For a brief description, see [Controls built for Field Service mobile](/dynamics365/guidance/resources/field-service-sample-library#controls-in-the-mobile-app).

- [Add booking statuses with custom icons](/dynamics365/guidance/resources/field-service-mobile-booking-status)
- [Add a control for taking notes](/dynamics365/guidance/resources/field-service-mobile-take-notes)
- [Add a mobile lookup control](/dynamics365/guidance/resources/field-service-mobile-add-lookup)
- [Disable clickthrough on lookup values in forms](/dynamics365/guidance/resources/field-service-mobile-disable-click)
- [Show more data in lists and subgrids](/dynamics365/guidance/resources/field-service-mobile-expand-grid-control)

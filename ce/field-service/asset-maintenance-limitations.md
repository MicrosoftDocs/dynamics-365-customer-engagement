# Known limitations (preview)

[!INCLUDE [public-preview-banner](../includes/public-preview-banner.md)]

Keep these limitations in mind while evaluating the preview.

- Preview features, schema, and behavior can change.
- Preview environments are disposable and might not upgrade to a mainline release.
- The feature isn't intended for production use.
- Template Asset Category, Manufacturer, and Model values help filter templates but aren't enforced when a template is applied.
- Service meter units (SMU)-based predicted dates depend on recent readings and a positive projected SMU-per-day rate.
- Regeneration doesn't change manually overridden due dates or details that already have generated work orders.

# View scheduling warnings in the mobile app

When a project manager opens a work order from a project task in Project Operations, the Field Service mobile app displays warnings if the schedule conflicts with the task’s planned dates or dependencies. You can view these warnings and review predecessor and successor project tasks.

1. Open the work order in the Field Service mobile app.

1. If the work is scheduled outside project constraints, scheduling warnings appear in the **Notifications** area at the top of the screen. Expand this section to view the warnings.

   :::image type="content" source="media/project-operations-integration-mobile-schedule.png" alt-text="Screenshot of scheduling warnings in the mobile app.":::

1. Scroll down to **Predecessor Project Tasks** to view the predecessor tasks. If a predecessor task isn't complete, you can't complete the work order until the predecessor task is finished.

1. Expand to select **Successor Project Tasks**.

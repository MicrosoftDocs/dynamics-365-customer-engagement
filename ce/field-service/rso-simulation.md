# Run Resource Scheduling Optimization as a simulation

As an admin, when you run an optimization as a simulation, you can see what the optimization results look like. Review the results closely before setting up a recurring schedule.

By using the simulation feature, you can review optimization results before pushing the assignments to all resources. You can also discard the results and rerun the optimization by adjusting the optimization parameters.

## How to trigger a simulation run

Use one of the following methods to run an optimization request in simulation mode:

1. **From the schedule board**: Select a schedule board with the custom web resource for Resource Scheduling Optimization configured. Select the **Optimization** options, set the optimization parameters, and select **Run as simulation**.

1. **From the optimization schedule**: Open the optimization schedule configuration and set **Run as simulation** to **Yes**. Publish the optimization schedule, and then run it.

After reviewing the results of a simulation run, you can apply or discard the changes.

# Set up bookable resource categories

Bookable resource categories help you group your bookable resources by type. For example, you can create categories like technician, supervisor, subcontractor, vehicle, or equipment.
  
1. In Field Service, go to the **Resources** area.

1. In the **Resources** area, under **Resource** in the left pane, select **Categories**.  
  
1. Select **New** to create a new resource category.  
  
1. Enter a **Name** for the category and an optional description.

1. Save the record.

1. Select **Related** > **Resource Category Associations**, and then add bookable resources for this category.

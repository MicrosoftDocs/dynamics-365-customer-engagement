# Dynamics 365 Activate overview (preview)

[!INCLUDE [preview-banner](~/../shared-content/shared/preview-includes/preview-banner.md)]

Dynamics 365 Activate is a unified, AI-assisted implementation and migration experience for Dynamics 365. It helps Microsoft customers, partners, and systems integrators understand existing business application environments, make informed transformation decisions, and accelerate migration and implementation.

Dynamics 365 Activate currently supports migration from Salesforce to Dynamics 365.

[!INCLUDE [preview-note](~/../shared-content/shared/preview-includes/preview-note-d365.md)]

## Migration approach

Dynamics 365 Activate helps you understand your source environment before migrating to Dynamics 365. 

- **Assessment**: It assesses data structures, configurations, customizations, processes, integrations, and dependencies to provide context for migration planning and solution design.

- **Planning**: Use the assessment results to identify migration scope, dependencies, complexity, and readiness. Review existing components and decide what to preserve, simplify, redesign, or exclude rather than automatically recreating the source system in Dynamics 365.

- **Execution**: This approach helps you prioritize migration work, address risks, and make informed decisions about data mapping, configuration, testing, and deployment.

## Salesforce migration

The Salesforce migration experience helps implementation teams assess a Salesforce environment, determine what should move to Dynamics 365, and execute the migration - from discovery and object mapping through schema deployment, data migration, and reconciliation.

For detailed capabilities, prerequisites, and the end-to-end process, see [Overview of Salesforce migration to Dynamics 365](migrate-salesforce-to-dynamics-365-overview.md).

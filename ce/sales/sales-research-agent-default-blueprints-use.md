# Run a starter prompt with a default blueprint (preview)

[!INCLUDE [preview-banner](~/../shared-content/shared/preview-includes/preview-banner.md)]

When your organization authors a [default blueprint](sales-research-agent-default-blueprints.md) for a starter prompt, you get the answer to that question in the same layout as everyone else who asks it, built from your own data. You don't need to configure anything.

[!INCLUDE [preview-banner](~/../shared-content/shared/preview-includes/preview-note-d365.md)]

## Run a starter prompt

1. Open Sales Research Agent.
2. Under **What would you like assistance with?**, select the business function for your question, such as **Strategic Account Planning**.
3. Under **Select a suggested topic below or ask any business question of your own**, select a starter prompt. Starter prompts that have a default blueprint are labeled **Uses custom blueprint**. The starter prompt fills the prompt box.

   :::image type="content" source="media/seller-starter-prompt.png" alt-text="Screenshot of the Sales Research Agent home page with a business function selected and a starter prompt labeled Uses custom blueprint.":::

4. Select **Submit** (the arrow), or press Enter.
5. Sales Research Agent researches your data and returns the answer in the authored layout: the headline metrics and summary, the charts, any web research, and key takeaways. To cancel while it runs, select **Stop generating**.

   :::image type="content" source="media/seller-result.png" alt-text="Screenshot of the answer to the Portfolio Pulse starter prompt, with the charts the blueprint defines, generated from the seller's data.":::

## What to expect

- **Same structure, your numbers.** Every user who runs the starter prompt gets the same blocks in the same order. The content is generated from the data you have access to, at the time you run it.
- **Same definitions.** Every query runs through the business function, so metrics such as attainment or pipeline are calculated the same way for everyone.

If you need a different kind of answer, ask your own question instead of selecting a starter prompt. Sales Research Agent then decides the shape of the answer itself.
